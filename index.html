1. React JSX Architecture ⭐⭐⭐ Core React

JSX Syntax, Expressions & Virtual DOM Compilation

JSX is a syntax extension for JavaScript that allows you to write HTML-like markup directly inside JS files. Under the hood, Babel compiles JSX tags into pure React.createElement() function calls.

// 5 Golden Rules of JSX:
1. Return a single parent element (or <>Fragment</>)
2. Close all tags explicitly: <img />, <input />, <br />
3. camelCase attributes: className, htmlFor, tabIndex, onClick
4. Embed dynamic JS expressions with curly braces: { 2 + 2 } or { user.name }
5. Use unique 'key' props when rendering lists via array.map()
2. Component Architecture ⭐⭐⭐ Core React

Functional Components, Props, State & Re-rendering

Components are reusable, self-contained UI building blocks. React functional components accept Props (read-only input data) and manage internal State (via useState), triggering lightning-fast Virtual DOM reconciliation upon changes.

function CounterCard({ title, badgeText }) {
  const [count, setCount] = useState(0);

  useEffect(() => {
    console.log(`Component updated! New count: ${count}`);
    return () => console.log("Cleanup before next effect");
  }, [count]);

  return (
    <div className="card">
      <h3>{title}</h3>
      <span>{badgeText}</span>
      <button onClick={() => setCount(prev => prev + 1)}>Count: {count}</button>
    </div>
  );
}
3. React Router v6 Navigation ⭐⭐⭐ SPA Architecture

Client-Side Routing, Dynamic Params & Programmatic Navigation

React Router is the standard routing library for React. It enables client-side navigation between different views without full-page reloads, providing dynamic URL parameters (useParams), imperative redirects (useNavigate), and nested route layouts (<Outlet />).

import { BrowserRouter, Routes, Route, Link, NavLink, useParams, useNavigate } from 'react-router-dom';

function App() {
  return (
    <BrowserRouter>
      <nav>
        <NavLink to="/" className={({ isActive }) => isActive ? "active" : ""}>Home</NavLink>
        <NavLink to="/courses">Courses</NavLink>
      </nav>

      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/courses" element={<CourseList />} />
        <Route path="/courses/:courseId" element={<CourseDetails />} />
        <Route path="/dashboard" element={<Dashboard />} />
        <Route path="*" element={<NotFound404 />} />
      </Routes>
    </BrowserRouter>
  );
}

// Dynamic Parameter Extraction Hook:
function CourseDetails() {
  const { courseId } = useParams();
  const navigate = useNavigate();
  return (
    <div>
      <h2>Course: {courseId}</h2>
      <button onClick={() => navigate('/courses')}>Go Back</button>
    </div>
  );
}

4. SPA Architecture ⭐⭐⭐ Priority

Client-Side Hash Routing

Single Page Applications swap views directly in memory without browser page reloads using the hashchange event.

Loading view...
Hash: #home Page Reloads: 0 ⚡ 
function router() {
  const hash = window.location.hash || "#home";
  container.innerHTML = routes[hash];
}
window.addEventListener("hashchange", router);
5. Architectural Overview ⭐⭐⭐ Priority

Single Page Application (SPA) vs Multi-Page Application (MPA)

How combining Client-Side Routing and REST APIs revolutionizes the modern web experience.

🚀 SPA (Single Page Application)

1 HTML file is served initially. Navigation updates the DOM via JavaScript. Only raw JSON is transferred across the wire via APIs.

Zero Page Reloads
📄 MPA (Multi-Page Application)

Every link click makes an HTTP request to the server, which renders and sends back a complete new HTML page, resulting in page flashes.

Full Reload Each Link
